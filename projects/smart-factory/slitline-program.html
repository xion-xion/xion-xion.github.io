SlitLine Quality Watchdog (Pressing Line - Phase 3)

Automating quality control enforcement by interlocking database logs directly with PLC operations.

Role Solo Software Engineer
Timeline December 2025 - January 2026
Technologies Niagara Workbench (SlitLine Program, Custom Logic & Software Interlocks), Microsoft SQL Server, RS-485 Modbus RTU
Team & Vendors Executed end-to-end as a solo software engineering project

The Problem & Context

Quality control operators frequently missed manual per-shift measurements. When defective material rolls went unnoticed, it delayed critical troubleshooting for both the pressing machines and the upstream casting machines, resulting in substantial material scrap and operational inefficiencies.

The Action & Integration

I engineered a purely software-driven automated interlock, designated as the "SlitLine" program, using Niagara Workbench. I programmed Niagara to continuously poll the central Microsoft SQL Server database to verify if shift measurements had been recorded. Incorporating operational buffers for shift handovers, the watchdog triggers a Modbus write command to halt the line's PLCs if QC entry compliance is not met within the window.

Measurable Business ROI

Enforced 100% compliance with quality control procedures. By guaranteeing early defect checks, the interlock successfully prevented the production of out-of-spec rolls, allowing operators to immediately trace upstream casting or pressing issues before wasting raw material.
