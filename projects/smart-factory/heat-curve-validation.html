Automated Heat Curve Validation System

Developing a custom Java watchdog program to check multi-zone temperature recipes in real-time.

Role Lead Systems Integration Engineer
Timeline May 2026
Technologies Custom Java Programming, SQL Database Integration, Niagara Workbench (Dynamic UI, Validation Algorithms, Real-time Dashboards)
Team & Vendors Developed the core architecture and custom Java program solo; managed 1 junior engineer for scaling

The Problem & Context

Manual configuration of material-specific temperature profiles ("heat curves") across multi-zone firing machines frequently suffered from human input errors. A single incorrect Set Point (SP) could take 1 to 2 weeks to identify, resulting in the scrapping of entire production batches and risking $50,000 to $80,000 in lost sales per incident.

The Action & Integration

I engineered a software watchdog using data already aggregated on the server. To avoid SQL database connection bottle-necks, I developed a custom Java program capable of fetching complete multi-zone recipes simultaneously. I designed an algorithm to compare entered SP/PV values against the SQL recipes in real-time, creating UI indicators (yellow for mismatch, red for failure) and managed a junior engineer to deploy it across 22 machines.

Measurable Business ROI

Completely eliminated the 1-2 week error detection lag, providing instantaneous alarms during changes if configuration mismatches are entered. The system reduced defective product output by 95% and safeguarded the company against catastrophic batch losses ($50,000 to $80,000 in sales per incident).
